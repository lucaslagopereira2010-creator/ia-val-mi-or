Ejemplo de integración mínima

Esta página de ejemplo solo contiene las 3 líneas necesarias para añadir el asistente como burbuja flotante a cualquier web del club. Ábrela en el navegador y verás la burbuja roja abajo a la derecha.

Para integrarlo en la web oficial, copia estas líneas antes de cerrar la etiqueta </body> (ajusta la ruta a la carpeta asistente/ según dónde la subas):

<link rel="stylesheet" href="asistente/edvm-chat.css">
<script src="asistente/base-conocimiento.js"></script>
<script src="asistente/edvm-chat.js"></script>
<script>EDVMChat.iniciarWidget();</script>
